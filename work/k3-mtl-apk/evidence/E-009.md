- raw_excerpt: |
    Adopted from the v3.1.0 Gemini payload (E-007), reimplemented independently (E-008): the Gemini
    request now carries generationConfig.responseMimeType=application/json with an ARRAY-of-OBJECT
    responseSchema of {index,text}, and parseStructuredTranslations places replies by index rather
    than by position. parseTranslationLinesFromJson tries the structured shape first and falls back
    to the pre-existing loose parsers, so a model that ignores the schema still works. A line the
    model declines to translate is now answered with a [CENSORED] stand-in for that line only,
    instead of failing the page.

    Not adopted: the OCR model swap to PaddleOCR v5. Houri sources models from
    joyeli/yakuyomi-engine GitHub releases (models-v2/models-v3). Porting PP-OCRv5 would require the
    detection and recognition weights plus ppocrv5_dict.txt published at a fetchable release URL,
    which only the maintainer can upload; without them the app cannot obtain its OCR at all. The
    v2.6.0 adaptation matrix had already recorded "do not replace wholesale" for the OCR stack.
